# Dubai Finance — PDF Presentation & Business Plan Materials

Yeh folder Dubai Finance ke PDF presentation, slides aur related design assets ke liye dedicate kiya gaya hai.

---

## 📁 Folder Structure

### 1. Presentation PDFs
* **`Dubai_Finance_Presentation.pdf`**: Dubai Finance official business presentation deck (converted from India Finance design to Dubai luxury theme).
* **`INDIA FINANCE USDT 5_ 10_ & 15_ Daily_260813_204143.pdf`**: Original reference presentation deck.

### 2. HTML Presentation & Deck Sources
* **`dubai_finance_presentation_usdt.html`**: Complete standalone presentation deck with high-res images and USDT BEP-20 branding.
* **`dubai_finance_presentation.html`**: Standard presentation deck HTML source.

### 3. Build & Extraction Scripts (Python)
* **`build_dubai_presentation_usdt.py`**: Python script to compile the complete USDT presentation slides with base64 assets.
* **`build_dubai_presentation.py`**: Primary presentation compilation script.
* **`extract_assets.py`**: PyMuPDF script to extract original images and visual vectors from reference PDF.
* **`setup_assets.py`**: Helper script for sourcing luxury backgrounds and icons.
* **`test_render.py`**: PDF rendering validation script.

### 4. Media & Asset Folders
* **`assets/`**: High-resolution photography (Dubai skyline, luxury lifestyle, crypto trading, office towers).
* **`pdf_assets/`**: Extracted icons, badges, charts, and graphics from reference presentation.
* **`extracted_pages/`**: High-DPI rendered page snapshots of the original reference deck.
* **`new_rendered_pages/`**: Rendered page snapshots of the generated Dubai Finance deck.
* **`extracted_text.txt`**: Extracted raw textual content from the original presentation.
